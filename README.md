**[DSS Link for QGIS](https://github.com/HundesaSiraj/dss-link-qgis)** — a QGIS plugin
that links HEC-DSS time series (HEC-HMS, HEC-RAS) to map stations: click a station
to explore its graph and table, browse the DSS catalog, and export temporal
GeoPackages or CSV. Developed with Marta Fikadu Shikur.
[⬇ Download the latest release](https://github.com/HundesaSiraj/dss-link-qgis/releases/latest)
